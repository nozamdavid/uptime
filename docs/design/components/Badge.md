# Badge

Badges are labels people create to group monitors; the person's chosen colour fills only the swatch.

- Text is always `ink` on `surface` with a `rule` border, so any user colour stays readable in both themes.
- Set the colour through `--badge-color` on the element. Never tint the text or the ground with it.
- Badges never mean status. A red badge is just a label.

The consumer provides the badge name and its colour.
